# MaderPader Blog

A simple blog app made with Node.js, Express, EJS, MongoDB, and cookie-based auth.

This web app is also deployed on render through this link (https://mpb-932d.onrender.com)
## Features
- Create, edit, and delete blogs
- Authentication
- Secure with Helmet
- MongoDB Atlas integration

## Deploy
You can deploy this app on Render or any Node-compatible hosting.
